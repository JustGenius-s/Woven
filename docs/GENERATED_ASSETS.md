# 原创视觉素材

封面和旅程插画是为 Woven 生成的原创图。仓库里是缩放后的应用资源，高分辨率原图不在 Git 中。

生成后的图只负责氛围和内容识别。标题、状态、进度和操作都由 ArkUI 绘制，不烘焙进图片。

## 约束

- 半扁平矢量结合轻绘画，柔和层次和细微纸张颗粒。
- 图中不放标题、按钮、Logo、水印、字母或数字。
- 音乐和阅读卡全出血。场景卡下方留较暗的文字区。旅程插画用透明背景。
- 词库封面为 3:2 横图，主体在右上，左侧和下方留浅色低细节区域给界面叠字。
