# 文法页实时语音

文法阅读页右上角的「语音伴读」直接发起全双工通话，用来讲解当前 PDF 页。服务是火山引擎豆包实时语音。密钥只保存在本机，不进入学习数据同步。

官方文档：[端到端实时语音](https://docs.volcengine.com/docs/6561/2549778)、[接入必读](https://docs.volcengine.com/docs/6561/2549732)。

## 配置

在「设置 → 实时语音 → 火山引擎」填写 API Key。只需要 Key，不需要 APP ID。从[语音控制台](https://console.volcengine.com/speech/new/setting/apikeys?projectName=default)获取。没有 Key 时，入口直接打开设置。

## 使用

1. 打开一课 PDF，点语音按钮并允许麦克风。接通后的欢迎语是固定提示，可以直接说「讲解这一页」。
2. 连接中，入口右侧展开为悬浮控制：静音、打开对话面板、挂断。面板和连接分开。收起面板后通话继续，字幕和静音状态保留。
3. 可以插话，或在面板里点「打断」。同一份 PDF 内翻页会带上最新页，不重新打招呼。
4. 挂断、换 PDF、离开阅读页、打开设置或切到后台会结束通话。原课文播放和通话互斥。

讲解由模型根据当前页文字生成，不预生成播客。教材默认用普通话讲，日语词句保留原文并按日语读。用户要求改用日语后，后续轮次沿用日语，直到要求切回中文。

## 数据

- 只有用户点语音入口或面板里的「开始语音对话」后，才会申请麦克风并连接服务。
- 接通后，麦克风音频和当前页提取出的文字会发到火山服务。参考文字最多 10,000 字，不把 PDF 里的命令当作系统指令。
- 纯扫描页或读不出文字时会告诉模型该页没有可读文字，不用上一页冒充。
- 应用不保存通话录音。字幕只留在当前阅读页。密钥不写入同步数据，错误提示不回显密钥或原始请求。

## 协议要点

- 地址：`wss://openspeech.bytedance.com/api/v3/duplex/realtime/dialogue`
- 请求头只带 `X-Api-Key`。
- 模型 `1.2.6.1`，音色 Vivi 2.0（`zh_female_vv_uranus_bigtts`）。
- 输入 PCM、16 kHz、单声道、16 bit LE，每 20 ms 一包。输出 `pcm_s16le`、24 kHz，供本机 AudioRenderer 播放。
- 翻页用 `session.update` 替换教材说明，确认后再发下一次更新。挂断先发 `session.close`。
