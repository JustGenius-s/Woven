# 开放内容接入说明

最后核对：2026-09-04

## 当前已经打包

- 阅读页只展示 Tadoku 免费书（L0入门 / L0–L5）：目录从云端拉取，点开后再把官方 PDF / 朗读 MP3 下到本机沙箱。阅读页用系统 PDF 阅读器展示官方电子书原页。有官方朗读的可以播放；句子时间轴只在对齐完成后才自动翻页和高亮。许可是 CC BY-NC-ND 4.0。
- 每篇作品在数据中保留作品卡 URL、作者、来源名称和权利说明；详情页直接展示这些信息。
- 音乐页当前 5 首内容是言葉 App 的原创学习文本与原创封面，不冒充真实歌曲，也没有假装提供音频播放。
- 词库 7,742 条 N5–N1 考试词已挂东京式音调：主源 Wadoku（CC BY-SA 3.0），缺条用 Kanjium 补。
- 另有 JMdict 常用词中不在 N5–N1 的条目，按报纸频段拆成「日常 / 一般 / 补遗」三级。字段说明见 `docs/VOCABULARY_SCHEMA.md`。

## 可继续接入的数据源

### MusicBrainz

适合补齐歌曲、录音、艺人、发行版等元数据。核心数据采用 CC0，补充数据采用 CC BY-NC-SA 3.0；两类数据不能在商业产品里不加区分地混用。MusicBrainz 不提供歌曲音频。API 客户端需要可识别的 User-Agent，并遵守每秒最多一次请求的限制。

### Wikimedia Commons

适合寻找可合法打包的朗读、发音与传统音乐音频，但 Commons 不是“一张总许可”。每个文件都要单独检查作者、许可版本、署名和相同方式共享要求。候选文件只记录在 `open-sources.json`，没有在尚未做播放器和署名页时直接塞入安装包。

### 青空文庫

只使用著作权已经消灭的作品。作品正文可以按青空文库规则复制、再分发和改编；应用仍保留作品卡、底本和输入校正来源，方便审计和回溯。仍处于著作权保护期的作品不进入离线包。

### Wadoku / Kanjium

适合补齐东京式音调。Wadoku 是当前打包的主源；Kanjium 只在精确匹配失败时使用，因为它可能混入商业辞典痕迹。NHK / 新明解原典不能进离线包。

### いろどり 生活の日本語

国際交流基金公开教材，允许用于教学与学习。应用只从云端按课拉取分课正文 PDF 和分课 MP3；入门至初级2用中文版并附语法练习册，初中级仅官方日文版、无练习册。不上传全书合集、插图集、目录和用法说明。官网：https://www.irodori.jpf.go.jp/

### にほんごたどく 無料の読みもの

NPO 多言語多読的免费书采用 CC BY-NC-ND 4.0。课堂可以发放未改动的官方 PDF，但禁止改写后再分发。因此应用打包官方电子书 PDF 和官方朗读 MP3，用系统 PDF 阅读器按原页展示，时间轴只做对齐，不加学习提示、不生成衍生 EPUB。署名、作品页链接和许可说明必须保留。用法见 https://tadoku.org/japanese/free-books/note/ 。

### Piper / sherpa-onnx

适合在设备上合成任意日语文本。运行时是 sherpa-onnx（Apache-2.0）；默认声线是 Piper `ja_JA-hi_fi_captain-medium`（MIT）。模型由 `npm run fetch:tts` 写入 `rawfile/tts/`，不进安装包仓库。五十音仍用已打包录音。用法见 [`docs/TTS.md`](TTS.md)。

### Tatoeba

适合扩充例句与发音。句子下载数据通常采用 CC BY 2.0 FR，部分贡献可选择 CC0；音频许可由每位贡献者逐条设定。因此接入时必须保存句子 ID、作者和许可，不能只下载文本或音频后丢掉归属信息。例句、音频和整句假名还没有写入词库，留给后期批量生成。

## 接入边界

1. 来源清单是允许进入内容流水线的白名单，不等于所有条目都可以直接商用。
2. 外部音频必须先完成播放器、离线缓存、署名与删除机制，再加入安装包。Tadoku 官方朗读已按此接入。
3. 远端内容要经过日语文本清洗、难度标注、重复检测和人工抽检，不能把 API 返回直接展示给用户。
4. Tadoku 免费书只按官方电子书 PDF 原页接入，朗读只用官方未改动的 MP3；改写故事、加解说或转成学习 EPUB 都属于改作。
5. 具体机器可读信息见 `entry/src/main/resources/rawfile/open-sources.json`。
