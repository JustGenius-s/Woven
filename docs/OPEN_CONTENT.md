## 尚未打包

| --- | --- | --- |
| [MusicBrainz](https://musicbrainz.org/) | 歌曲、录音、艺人元数据 | 核心数据 CC0，补充数据 CC BY-NC-SA 3.0，不能混用。不提供音频。客户端需要可识别的 User-Agent，且每秒最多请求一次 |
| [Wikimedia Commons](https://commons.wikimedia.org/) | 朗读、发音、传统音乐 | 每个文件单独核对作者、许可和署名。候选只记在 `open-sources.json` |
| [Tatoeba](https://tatoeba.org/) | 例句和发音 | 句子多为 CC BY 2.0 FR，音频许可逐条不同。必须保留句子 ID、作者和许可 |

## 接入边界

1. 白名单只表示允许进入流水线，不表示条目都可以商用。
2. 外部音频要先有播放、离线缓存、署名和删除，再进安装包。Tadoku 官方朗读已按此接入。
3. 远端文本要经过清洗、难度标注、去重和抽检，不能直接展示 API 返回值。
4. Tadoku 只使用未改动的官方 PDF 和 MP3。改写、加解说或转成学习用 EPUB 都属于改作。
5. 仍在著作权保护期内的青空文库作品不进离线包。
