# 开放内容接入说明

最后核对：2026-08-31

## 当前已经打包

- 阅读页使用 5 篇青空文库作品的学习节选：`蜘蛛の糸`、`吾輩は猫である`、`注文の多い料理店`、`ごん狐`、`走れメロス`。
- 每篇作品在数据中保留作品卡 URL、作者、来源名称和权利说明；详情页直接展示这些信息。
- 音乐页当前 5 首内容是言葉 App 的原创学习文本与原创封面，不冒充真实歌曲，也没有假装提供音频播放。

## 可继续接入的数据源

### MusicBrainz

适合补齐歌曲、录音、艺人、发行版等元数据。核心数据采用 CC0，补充数据采用 CC BY-NC-SA 3.0；两类数据不能在商业产品里不加区分地混用。MusicBrainz 不提供歌曲音频。API 客户端需要可识别的 User-Agent，并遵守每秒最多一次请求的限制。

### Wikimedia Commons

适合寻找可合法打包的朗读、发音与传统音乐音频，但 Commons 不是“一张总许可”。每个文件都要单独检查作者、许可版本、署名和相同方式共享要求。候选文件只记录在 `open-sources.json`，没有在尚未做播放器和署名页时直接塞入安装包。

### 青空文庫

只使用著作权已经消灭的作品。作品正文可以按青空文库规则复制、再分发和改编；应用仍保留作品卡、底本和输入校正来源，方便审计和回溯。仍处于著作权保护期的作品不进入离线包。

### Tatoeba

适合扩充例句与发音。句子下载数据通常采用 CC BY 2.0 FR，部分贡献可选择 CC0；音频许可由每位贡献者逐条设定。因此接入时必须保存句子 ID、作者和许可，不能只下载文本或音频后丢掉归属信息。

## 接入边界

1. 来源清单是允许进入内容流水线的白名单，不等于所有条目都可以直接商用。
2. 外部音频必须先完成播放器、离线缓存、署名与删除机制，再加入安装包。
3. 远端内容要经过日语文本清洗、难度标注、重复检测和人工抽检，不能把 API 返回直接展示给用户。
4. 具体机器可读信息见 `entry/src/main/resources/rawfile/content/open-sources.json`。
