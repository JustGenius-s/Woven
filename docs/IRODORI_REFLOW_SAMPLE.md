# Irodori 入门第 1 课完整重排版

第 1 课（`irodori-a1-l01`）在文法教材列表中直接打开完整重排版，替代默认 PDF 阅读入口。目录按原 PDF 第 1—18 页连续排列，覆盖会话练习、信息表情、听力脚本、假名表和日本生活说明。右上角保留课文音频入口，可选曲、播放、切换和拖动进度；音频按曲下载，不阻塞内置教材阅读。退出阅读会释放音频播放器。

原 PDF 源文件和既有缓存保留；不支持 Reader Kit 的设备继续使用 PDF 页面。支持设备上返回直接回到文法教材列表。重排阅读进度延续此前预览版本的独立记录。当前重排阅读页不提供 PDF 页面的实时讲解入口。

为保持已有入口兼容，脚本、资源文件、常量及内部 ID 暂保留 `sample` 名称；它们现在包含完整第一课，不再是抽页样张。其他入门课程由独立的批量流程生成，见 [入门课程重排](IRODORI_STARTER_REFLOW.md)。

## 构建

需要 Node.js、PDF.js，以及 Python、PyMuPDF、fontTools。以官方中文 Starter 第 1 课 `X_L01_CN.pdf` 为输入，原文件不入库。

```sh
node scripts/lib/irodori/extract-fonts.cjs /path/to/X_L01_CN.pdf .cache/irodori-fonts
python3 scripts/build-irodori-sample.py /path/to/X_L01_CN.pdf
```

生成 EPUB、`IrodoriSampleContent.ets`，以及 `.cache/irodori-sample/` 中的 XHTML、图片、字体和 `audit.json`。源文件必须为审校的 18 页版本，字体缓存绑定源 PDF SHA-256。EPUB 和字体时间戳固定，内容哈希用于独立缓存版本。

- `build-irodori-sample.py`：字符提取、注音关联、前三页版式、内容审计和 EPUB 打包。
- `scripts/lib/irodori/lesson_layouts.py`：第 4—18 页人工审校的区域和版式规则。
- `scripts/lib/irodori/book.css`：手机重排样式。
- `scripts/lib/irodori/extract-fonts.cjs`、`source_fonts.py`：提取、修复、转换和打包原字体。

## 内容与版式

- 正文、中文、罗马字和注音使用原 PDF 内嵌字体，并保留字号比例和颜色。原字体轮廓携带字重，避免系统合成粗体。第 15 页的明朝体与手写体分别使用对应源字体。
- 图标、装饰标题、插图、照片和聊天截图使用原页局部图像。插图中的答题标注随图片缩放；其他正文可调字号。
- 第 1—3 页保留已确认的学习目标、四幅练习插图、左右会话气泡、尖角、箭头、描边和虚线。
- 第 4—8 页延续相同处理，完整保留各练习编号、音频编号、选项和答题标注。较长的感谢会话按上下顺序排列，避免窄屏左右挤压。词汇与其中文释义、罗马字整组显示。
- 第 9—10 页保留信息表情和聊天界面的原图；题干和说明为活文字。
- 第 11—13 页保持听力脚本的音频编号、A/B/C 发言顺序，以及日文与罗马字的对应关系。
- 第 14—15 页把宽纸张上的并排假名表改为纵向排列的原生表格，保留行列、空格、脚注和读音颜色；按行分页。第 15 页完整保留罗马字输入说明。
- 第 16 页长音、促音词汇与插图成组展示，保留橙色强调和蓝色罗马字。
- 第 17—18 页的中日双语文化说明按段落重排，保留全部照片及人物插图。
- 原课页眉、页号及版权署名保留。手机上的一屏不等于原 PDF 一页，分页和换行随字号及屏幕尺寸变化。

## 内容与字体验证

构建检查所有正文非空字符的区域归属，遗漏或重复立即失败；随后对实际生成的 XHTML 文字和图像替代文本再次计数，防止注音序列化等环节丢字。

当前全课共 7,812 个正文字符，其中 163 个由局部原图承载；203 组注音。所有页的区域归属与输出字符检查均通过。打包后的 7,634 个使用嵌入字体的非空活文字字符逐字检查 cmap 覆盖；这个统计与正文区域统计范围不同，不能简单相减。24 个实际使用的字体子集合计 409,108 字节。18 个章节的 XML、资源引用及 spine 顺序检查通过。

`extract-fonts.cjs` 使用 PDF.js 修复原嵌入字体，记录原 Unicode 到临时字体字形的映射。`source_fonts.py` 重建 Unicode cmap，CFF 轮廓以 0.5 字体单位的误差上限转换为 TrueType，保留字宽与垂直度量，设置独立字体名称。输出字体重新加载检查 cmap；没有对应源字体的非空字符会令构建失败。所有字形均来自源 PDF，没有下载替代字体。

此设备的 Reader Kit 会将 `src:url(...) format(...)` 中的格式提示拼进资源路径，导致字体回退。因此生成的声明只使用合法的 `src:url(...)`，由 BookParser 直接解析嵌入字体。图片尺寸在需要时使用内联样式，避免原生阅读器的表格图片规则放大小图标。

## 验收与边界

全部 18 页均渲染为手机宽度预览并逐页核对；构建、安装和真机检查覆盖会话、练习、听力脚本、假名表及文化说明。内容审计不能代替视觉检查，浏览器预览也不能代替原生阅读器验证。

这是针对本课的人工审校转换规则，不是任意 PDF 的自动转换器。后续扩展新课仍需逐页定义结构并核对图片、练习、脚注和字体。纸张布局中的绝对位置、跨表虚线连接、抗锯齿以及手机换行并非逐像素复制。
